# HyperPersonalization (InsightRecs)

## Overview
HyperPersonalization (InsightRecs) is an AI-assisted shopping recommendation web application built with Flask. It provides a personalized shopping journey with registration/login, onboarding-based preference capture, recommendation search, dashboard insights, cart actions, event-based offers, birthday offers, and email-trigger workflows.

The app combines user behavior, preferences, demographics, and vector search to generate relevant product recommendations in real time.

This repository contains the Flask app, HTML templates, and static assets to run the complete hyper-personalized shopping workflow locally.

## Technologies

- **UI / App:** Flask (Python), HTML/CSS/JavaScript templates
- **AI / LLM:** LangChain + Vertex AI (`langchain_google_vertexai`, Gemini + embeddings)
- **Vector Search:** Qdrant Cloud (`qdrant-client`)
- **Persistence:** MongoDB (users, products, preferences, interactions, cart, events, email triggers)
- **Session Management:** `flask-session`
- **Observability / Tracing:** Opik (`opik`), Langfuse
- **Email Integration:** SMTP (`smtplib`) for cart/offer/recommendation notifications

## Prerequisites

- Python 3.9 or higher (3.10+ recommended)
- `pip` package manager
- Git
- Access to a MongoDB instance (local or Atlas)
- Access to a Qdrant instance (Cloud or local)
- Google Cloud Vertex AI access with service account JSON (for embeddings + LLM)
- (Optional) SMTP credentials for sending emails

## Usage

### 1) Clone the repository

```bash
git clone <your-repository-url>
cd HyperPersonalization
```

### 2) Create and activate a virtual environment (recommended)

```bash
# Windows
python -m venv .venv
.\.venv\Scripts\activate

# Linux / macOS
python -m venv .venv
source .venv/bin/activate
```

### 3) Install required packages

If you add a `requirements.txt`, use:

```bash
pip install -r requirements.txt
```

Or install directly:

```bash
pip install flask flask-session python-dotenv pymongo qdrant-client langchain-core langchain-google-vertexai google-auth vertexai numpy python-dateutil langfuse opik
```

### 4) Configure credentials and environment

Create a `.env` file in the project root and configure at least:

- `MONGO_URI` — MongoDB connection string
- `SMTP_USERNAME` — SMTP sender username/email (optional)
- `SMTP_PASSWORD` — SMTP password/app password (optional)
- `SMTP_SERVER` — SMTP host (optional)
- `SMTP_PORT` — SMTP port (default `587`) (optional)
- `GOOGLE_APPLICATION_CREDENTIALS` — path to service account JSON
- `OPIK_API_KEY` — Opik API key (optional, if tracing enabled)
- `OPIK_WORKSPACE` — Opik workspace (optional)

> Note: The current code in `app.py` contains hardcoded credentials/keys and service-account path defaults. For production-safe usage, replace hardcoded values with environment variables.

### 5) Start the app

```bash
python app.py
```

The app starts on:

- `http://localhost:5000`

### 6) Run the workflow

1. Open the app in browser.
2. Register a user and login.
3. Complete onboarding preferences.
4. Use dashboard/search to get personalized recommendations.
5. Add/remove products in cart and track interactions.
6. Logout to trigger configured email workflows.

## Output and Persistence

Data and runtime artifacts used/generated by the app include:

- **MongoDB collections**
  - `products`
  - `demographics`
  - `user_preferences`
  - `cart`
  - `users_collection`
  - `user_interactions`
  - `events`
  - `email_triggers`

- **Qdrant collection**
  - `product_embeddings` (vector index for similarity search)

- **Log files** (auto-created in `logs/`)
  - `demographic_recommendations.log`
  - `other_users_recommendations.log`
  - `user_interactions.log`
  - `user_preferences.log`
  - `birthday_celebrations.log`
  - `email_triggers.log`
